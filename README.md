# Parking Lot Manager

CSC243 Python Project — Fall 2026

## Project Description
This program manages a parking lot with 10 spaces. Users can park cars, remove cars, check available parking spaces, and calculate parking fees.

The parking fee is $2 per hour.

## Features
1. Park a Car
2. Remove a Car
3. View Parking Lot
4. Parking Statistics
5. Save Data
6. Load Data
7. Exit

## How to Run
1. Open Spyder.
2. Click File → Open.
3. Select the parking_lot.py file.
4. Press F5 or click Run.
5. The menu will appear in the IPython Console.
6. Enter a number from 1 to 7.

## Testing
The program can be tested by parking a car, entering a duplicate plate number, removing a car, checking parking fees, viewing available spaces, and saving and loading data.

Detailed test results are recorded separately.

## Classes
**Car:** Stores the car's plate number and parking spot and calculates parking fees.

**ParkingLot:** Manages parked cars, available spaces, earnings, and saved records.
